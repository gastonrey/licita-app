licita

Agent-native public procurement intelligence — Spain first, EU TED data. Built for AI agents, not dashboards.

This is a server application (REST API + MCP server + x402-shaped payments), delivered as source with Docker packaging. When the container is running, the service exposes its own discovery surfaces; this page is the static project overview.

Run it

docker compose up --build
# then, in another shell:
npx tsx scripts/smoke-agent.ts   # autonomous agent demo: discover → price → pay → consume

Full instructions, env vars, and payment semantics: see README.md in this repository.

Payment flow (dev mode)

GET /v1/search?cpv=72          → 402 { x402Version, accepts, hint }
POST /v1/dev-faucet {"endpoint":"GET /v1/search"}  → { token }
GET /v1/search?cpv=72  +  X-PAYMENT: <token>     → 200 { data, meta{ price_usd, provenance } }

Real x402 facilitator support is a clean seam (X402PaymentProvider), not wired in the MVP. Stripe is not a dependency.
